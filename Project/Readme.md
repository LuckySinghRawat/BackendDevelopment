# YouTube Clone Backend

This project is a learning-focused YouTube clone backend built with Node.js, Express, MongoDB, Mongoose, JWT authentication, Multer, and Cloudinary. It covers API design, user management, media uploads, authentication, and subscription-related data.

## Phases

- [Phase 1](./documentation/phase1.md): Set up the project structure and install dependencies.
- [Phase 2](./documentation/phase2.md): Learn MongoDB, MongoDB Atlas, asynchronous JavaScript, and development scripts.
- [Phase 3](./documentation/phase3.md): Build the request pipeline with Express middleware, utilities, models, and pagination.
- [Phase 4](./documentation/phase4.md): Handle file uploads, Cloudinary storage, HTTP concepts, and API testing.
- [Phase 5](./documentation/phase5.md): Implement user registration, routes, controllers, and debugging fixes.
- [Phase 6](./documentation/phase6.md): Implement login, logout, JWT verification, cookies, and user updates.
- [Phase 7](./documentation/phase7.md): Add token refresh, password changes, profile retrieval, and profile image updates.
- [Phase 8](./documentation/phase8.md): Add subscriptions, profiles, watch history, and protected user routes.

## Learnings

Through this project, I learned how to build a backend application step by step using Node.js and Express.

- Set up a structured backend project and manage development dependencies.
- Connect an Express application to MongoDB Atlas with Mongoose.
- Design database models for users, videos, subscriptions, and watch history.
- Build REST APIs using routes, controllers, middleware, and HTTP methods.
- Handle JSON data, form data, cookies, CORS, and HTTP headers.
- Upload and manage images and videos using Multer and Cloudinary.
- Hash passwords securely with bcrypt and use Mongoose middleware.
- Implement user registration, login, logout, JWT authentication, and token refresh.
- Protect routes with authentication middleware and secure cookies.
- Update user profiles, avatars, cover images, passwords, and account details.
- Use MongoDB aggregation to retrieve related data such as watch history.
- Test APIs with Thunder Client and Postman and debug issues across middleware, controllers, and utilities.

Overall, this project helped me understand how the main parts of a production-style backend work together, from receiving a request to validating data, communicating with the database, managing files, securing users, and returning a consistent response.
